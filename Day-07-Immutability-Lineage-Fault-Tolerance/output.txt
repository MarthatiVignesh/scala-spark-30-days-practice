====================================================
RDD Immutability
====================================================
RDDs are immutable.
Transformations never modify the original RDD.
Each transformation creates a new RDD.
Example: students remains unchanged after filter().

====================================================
Fault Tolerance
====================================================
Spark stores RDD lineage information.
If a partition is lost, Spark can recompute it
using the transformations that created that partition.
This provides fault tolerance without requiring
every intermediate RDD to be permanently stored.

====================================================
Transformation Types
====================================================

map    -> Narrow transformation
collect -> Action
