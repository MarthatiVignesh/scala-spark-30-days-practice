--- 8. RDD vs DATAFRAME vs DATASET ---
RDD       : Low-level distributed collection, flexible and object-oriented.
DataFrame : Distributed table of Rows with schema and SQL/DataFrame APIs.
Dataset   : Typed distributed collection with compile-time type safety.
Catalyst  : Spark SQL optimizer used for DataFrame/Dataset query plans.
Type Safety: Dataset provides compile-time checking for typed operations.
