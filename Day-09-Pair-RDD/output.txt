7. reduceByKey() vs groupByKey()
reduceByKey():
- Performs local aggregation before shuffle.
- Transfers less data across the network.
- Usually more efficient for aggregation.

groupByKey():
- Groups all values belonging to each key.
- More data may be transferred during shuffle.
- Can use more memory for large datasets.

Performance comparison:
reduceByKey() -> preferred for sum/count/aggregation.
groupByKey()  -> useful when all individual values are required.
