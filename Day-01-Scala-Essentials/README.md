# Day 1 - Scala Essentials

## Objective

Practice Scala fundamentals using immutable collections and build a small student-grade processor using only Scala collections.

## Day 1 Requirements

- Use `val`
- Use `var`
- Use `lazy val`
- Work with immutable collections
- Use `for-comprehension` with `yield`
- Compare `List`, `Vector`, `Set`, and `Map`
- Create a `Logger` trait
- Implement the trait in two classes
- Build a student-grade processor using Scala collections

## Project: Student Grade Processor

The program stores student names and marks and performs the following operations:

1. Calculates student grades.
2. Displays all students and their grades.
3. Finds students who scored 80 or above.
4. Calculates average marks.
5. Demonstrates `List`.
6. Demonstrates `Vector`.
7. Demonstrates `Set`.
8. Demonstrates `Map`.
9. Demonstrates `val`, `var`, and `lazy val`.
10. Demonstrates a `for-comprehension` with `yield`.
11. Demonstrates a `Logger` trait with two implementations.
