====================================================
Jobs, Stages, Tasks and Partitions
====================================================
Job: Created when an action such as collect() or count() runs.
Stage: A group of operations separated by shuffle boundaries.
Task: Work performed on one partition.
Partition: A logical division of an RDD.

For this reduceByKey pipeline:
Stage 0: textFile -> filter -> map
Stage 1: reduceByKey -> collect
reduceByKey creates a shuffle boundary.

====================================================
Narrow vs Wide Transformations
====================================================
filter()     -> Narrow transformation
map()        -> Narrow transformation
reduceByKey() -> Wide transformation
collect()    -> Action
count()      -> Action

====================================================
DAG Explanation
====================================================
Spark builds a Directed Acyclic Graph (DAG) from transformations.
The DAG represents dependencies between RDDs.
Narrow transformations can be pipelined within a stage.
Wide transformations such as reduceByKey require a shuffle.
Shuffle creates a boundary between stages.
